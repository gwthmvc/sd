# The Path of Discipline

A single-page website exploring how "spiritual power" — deep focus, inner strength, and self-control — is built through consistent discipline and mental mastery.

## What It Is

A self-contained HTML page (no dependencies, no build step) that walks through:

- What inner power actually means
- The two foundational pillars: **discipline** (daily practice) and **control** (moment-to-moment mastery)
- The classical stages of the path (restraint → breath → sense-withdrawal → concentration → meditation → equanimity)
- A practical daily routine
- A grounded note on keeping expectations realistic
